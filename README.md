# CLICK-GO

Plataforma de mobilidade urbana multi-cidade e multi-franquia.

## Stack
- Next.js + TypeScript
- Supabase (Postgres, Auth, Realtime)
- Vercel
- GitHub

## Módulos iniciais
- Super Admin
- Cidades
- Franquias
- Motoristas
- Corridas

## Configuração
Copie `.env.example` para `.env.local` e informe a chave pública do Supabase.
